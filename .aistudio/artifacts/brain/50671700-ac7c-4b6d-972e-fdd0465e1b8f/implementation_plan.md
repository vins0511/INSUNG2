# [인성체크리스트] 초등학생 자기성찰 및 인성 성장 맞춤형 지원 시스템

초등학교 학생의 자기평가와 담임교사의 관찰 평가를 종합 비교·분석하여, 학생 스스로 인성덕목(배려·존중·책임·정직·협동)을 성찰하고 생활 속 실천 목표를 수립할 수 있도록 돕는 순수 정적 웹 애플리케이션(GitHub Pages 호스팅 지원)입니다.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> **필수 조건 충돌 지점 안내 및 권장 해결 방안 (Decision Summary)**
> 
> 1. **기술 스택 충돌 (초기 템플릿 Vite React vs 사용자 지침 순수 HTML·CSS·JS 단일 파일)**
>    - *충돌*: 초기 환경은 Vite+React 템플릿이나, 추가 지침은 "무조건 html, css, js만 사용", "GitHub Pages 호스팅", "완전한 단일 index.html 한 개(CSS/JS 내포)".
>    - *해결 방안*: 단일 `index.html` 내부에 모든 구조, 스타일(초등 눈높이 친근한 CSS), 반응형 자바스크립트를 완벽하게 통합 구축합니다. GitHub Pages 배포 시 해당 `index.html` 파일 하나만으로 즉시 구동됩니다.
>
> 2. **AI 피드백과 외부 API 금지 충돌 (AI 분석 필요 vs LLM API 호출 불가)**
>    - *충돌*: 학생 맞춤형 AI 피드백을 요구하지만 외부 LLM API, Node 서버, npm 라이브러리 사용이 전면 금지되어 있습니다.
>    - *해결 방안*: 브라우저 내에서 덕목별 점수차(학생 vs 교사), 강점 영역, 노력 필요 영역, 가정/학교 격차를 다각도로 연산하여 초등학생 눈높이의 친절하고 격려 넘치는 문장을 생성하는 **'내장형 지능형 AI 조력자 엔진(Rule-based Adaptive AI Engine)'**을 순수 자바스크립트로 구현합니다.
>
> 3. **구글 스프레드시트 연동과 정적 호스팅 보안 충돌**
>    - *충돌*: 구글 스프레드시트를 데이터 저장소로 사용해야 하나, GitHub Pages 정적 웹 환경에서는 프런트엔드에 비밀키를 보관할 수 없습니다.
>    - *해결 방안*: 브라우저 `localStorage`를 기본 저장소로 사용하여 즉시 끊김 없이 동작하게 하고, 5개 시트 스키마를 완벽 지원하는 **별도 Google Apps Script(`Code.gs`) 코드**와 웹앱 URL 연동 입력창을 제공합니다. 또한 학급 데이터 백업용 5개 시트 표준 CSV 내보내기/불러오기 기능을 함께 탑재합니다.
>
> 4. **권한 구분과 무로그인 제약 충돌**
>    - *충돌*: 학생별 권한 격리(타 학생 데이터 열람 방지) 및 교사 권한이 필요하지만, 비밀키/로그인 기능 임의 추가는 금지되어 있습니다.
>    - *해결 방안*: 상단에서 [학생 모드]와 [교사 모드]를 명확히 구분하고, 학생 모드 진입 시 학년·반·가상학생(S01~S20)을 선택하면 해당 학생의 평가 데이터만 열람·작성되도록 세션을 격리합니다. 교사 모드에서는 학급 전체 20명의 관찰 및 비교 현황을 관리합니다.

## 1. Overview & Core Concept

- **목적**: 학생 스스로 생활 모습을 돌아보는 자기평가와 교사의 관찰 평가를 결합하여, 평가나 서열화가 아닌 **'자기성찰과 실천적 행동 변화'**를 촉진하는 교육용 도구입니다.
- **주 사용자**:
  - **초등학생 (저학년~중학년)**: 큰 글씨, 직관적인 1~4점 척도 아이콘(새싹→꽃→나무→열매), 쉬운 질문 문항.
  - **담임교사**: 학생별 관찰 체크리스트 작성, '관찰하지 못함' 처리 기능, 학급 전체 및 개별 비교 대시보드.
- **가상 데이터**: 20명 학생 (ID: `S01` ~ `S20`, 표시명: `학생01` ~ `학생20`), 3학년 1반 기본 세팅.
- **5대 인성덕목**: 배려, 존중, 책임, 정직, 협동 (각 덕목별 가정생활 2문항 + 학교생활 2문항 = 총 20개 문항).

## 3. 핵심 규칙 & 평가 로직 (Core Rules)

1. **점수 계산 및 '관찰하지 못함' 제외 규칙**:
   $$\text{덕목별 점수} = \frac{\sum (\text{유효 응답 점수})}{\text{유효 응답 문항 수}}$$
   교사가 특정 가정생활 문항 등을 '관찰하지 못함'으로 선택한 경우 분모와 분자에서 모두 제외하여 왜곡 없는 평균 점수를 산출합니다.
2. **AI 맞춤형 피드백 생성 알고리즘 (Rule-based AI Mentor Engine)**:
   - **강점 발굴**: 학생·교사 평균이 가장 높은 덕목을 선정하여 아낌없는 칭찬과 구체적 행동 언급.
   - **차이 분석 & 성찰 질문**: 학생 평가와 교사 평가 간 차이가 큰 항목(1점 이상)을 추출하여 "어느 쪽이 틀린 것이 아니라, 학교와 집에서의 모습 차이일 수 있어요. 왜 그렇게 느꼈는지 함께 생각해볼까요?"라는 중립적 성찰 질문 제시.
   - **실천 목표 추천**: 성장이 가장 기대되는 덕목을 바탕으로 실천하기 쉬운 1~3문장 이내의 친절한 행동 과제 추천.
3. **학생 주도 최종 자기평가 원칙**:
   - AI는 조력자일 뿐 점수를 결정하지 않습니다. 학생이 피드백과 교사 관찰 점수를 확인한 뒤, 자신의 최종 자기평가 점수를 직접 선택합니다.
4. **접근 권한 및 학생 보호**:
   - 학생 모드에서는 현재 선택된 학생ID(`S01` 등)의 기록만 조회·수정 가능합니다. 타 학생 결과 열람 및 비교 랭킹을 원천 차단합니다.
   - 교사 모드에서는 20명 전체 학생 목록과 평가 완료 여부(학생완료/교사완료/최종완료)를 조회하고 인쇄/저장할 수 있습니다.

## 5. 모호한 조건 대응 및 이번 버전에서 제외할 기능

### 모호한 조건 대응
1. **Google Apps Script 연동 방식**: 사용자가 구글 드라이브에서 Apps Script를 만들고 배포할 수 있도록 완성된 `Code.gs` 전문과 설정 가이드를 앱 내 '설정/연동' 모달에 제공합니다. Apps Script URL이 없는 경우에도 `localStorage`를 통해 100% 정상 작동하며 CSV 다운로드가 가능합니다.
2. **학생 변경 시 상태 격리**: 학생 드롭다운 변경 시 해당 학생의 미완료 작성 내용 저장 여부를 확인 후 안전하게 전환합니다.

### 이번 버전에서 제외할 기능 (Out of Scope)
- 외부 유료 LLM API 직접 호출 (지침에 따라 브라우저 내장 스마트 조력자 엔진으로 대체)
- 서버사이드 사용자 비밀번호 암호화 및 복잡한 Auth 인증 시스템 (초등 눈높이 간이 모드 전환 적용)
- 타 학생간 순위 매기기 또는 학급 내 비교 랭킹 시스템 (인성 교육 취지 및 보안 지침에 따라 배제)

## 6. 직접 실행할 검사 순서 (Execution Verification)

### [정상 시나리오]
1. **학생 로그인 & 자기평가 진행**:
   - 학생 모드에서 `학생01 (S01)` 선택 -> 5대 덕목 20개 문항에 1~4점 체크.
   - 모든 문항 선택 시 상단 진행률이 100%가 되고 '자기평가 저장' 버튼 활성화 확인.
2. **교사 관찰 평가 & 관찰 제외 처리**:
   - 교사 모드로 전환 -> `학생01` 선택 -> 체크리스트 작성. 특정 가정 문항을 '관찰하지 못함'으로 선택.
   - 점수 연산 시 해당 문항이 분모에서 정상 제외되는지 확인.
3. **비교 차트 & AI 맞춤형 피드백 생성**:
   - 학생·교사 평가 완료 시 우측에 덕목별 비교 막대/차트 렌더링 확인.
   - AI 피드백 영역에 칭찬(잘한 점), 성찰 질문, 추천 실천 목표가 다정하고 친절한 문장으로 표시되는지 확인.
4. **최종 자기평가 & 실천 목표 설정**:
   - 하단에서 학생이 자신의 최종 점수를 직접 조절하여 결정하고 실천 목표 입력/선택 후 저장.
5. **성장 이력 누적 확인**:
   - 날짜를 달리하거나 회차를 추가하여 재평가 시 이전 평가 대비 성장 변화 지표 및 추이 그래프 표시 확인.
6. **교사 학급 대시보드 및 출력**:
   - 교사 모드에서 20명 학생의 현황 요약표 확인 및 결과 인쇄/CSV 내보내기 기능 동작 확인.

### [예외 시나리오]
1. **필수 문항 누락 검사**: 20개 문항 중 일부를 미체크한 상태에서 완료 버튼 클릭 시 미응답 문항 번호 하이라이트 및 안내 토스트 표시 확인.
2. **범위 외 점수 방어**: 1~4점 범위를 벗어난 비정상 데이터 입력 차단 확인.
3. **타 학생 데이터 접근 차단**: 학생 모드에서는 오직 선택된 학생의 데이터만 렌더링되며, 다른 학생의 데이터가 혼입되지 않는지 확인.
4. **오프라인/스크립트 연결 실패 방어**: 스프레드시트 URL이 잘못되었거나 오프라인일 때 에러 알림과 함께 로컬 데이터는 안전하게 보존되는지 확인.
